# 💻 SalesPlus Frontend Web Application

Next.js 16 (App Router) client application for the SalesPlus Vehicle Sales & Dealership ERP System.

For complete system documentation, full feature breakdown, and environment configuration, please refer to the [Root README.md](../README.md).

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The frontend web application runs at: `http://localhost:3000`

For a deployed API, set `NEXT_PUBLIC_API_URL` to the public backend URL (for example,
`https://api.example.com`). Without it, local development uses the backend on port 3001
of the current host.

---

## 📜 Available Scripts

- `npm run dev` - Launch Next.js development server
- `npm run build` - Create production build
- `npm run start` - Run production server
- `npm run lint` - Run ESLint checks

---

## 🎨 Tech Stack & UI

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Components**: Base UI & Shadcn components
